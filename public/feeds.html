Feeds & Embeds

Take EventMedium's upcoming-events catalogue anywhere — RSS for readers and automations, JSON for apps, and a drop-in widget for your site or community page. Every item links back to the event on EventMedium.

RSS feeds

Standard RSS 2.0, refreshed hourly, upcoming events only. Filter with theme, city, or region query params — combine them freely.

All upcoming events/api/events/rss
By theme/api/events/rss?theme=AI
By city/api/events/rss?city=London
By country/api/events/rss?region=Australia
Combined/api/events/rss?theme=FinTech&city=Singapore
JSON feed

Same catalogue as structured JSON — for apps, newsletters, and automations. Open CORS, so you can fetch it from any site. Supports theme, city, region, status (upcoming | past | all) and limit.

GET https://www.eventmedium.ai/api/events/feed.json?theme=AI&limit=10
Embeddable widget

One script tag renders a live "Upcoming Events" card on any site — isolated styles, event images, and a built-in call-to-action that sends visitors to Nev. Great for community pages, newsletters, and partner sites.

<script src="https://www.eventmedium.ai/widget.js"
        data-theme="AI" data-city="London" data-limit="5"></script>

Prefer an iframe? Same output, fixed frame:

<iframe src="https://www.eventmedium.ai/embed.html?theme=AI&limit=5"
        width="420" height="480" frameborder="0"></iframe>

Attributes: data-theme, data-city, data-region, data-limit (max 20), data-title.
